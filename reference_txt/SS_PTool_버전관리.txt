SS Optical Performance Tool 버전 관리

버전 표기 규칙
- 형식: VMajor.Minor.Patch
- Major: 호환성이 크게 변경되는 제품 단위 변경
- Minor: 측정 모드 또는 주요 기능 추가
- Patch: 오류 수정, UI 개선, 검출 성능 개선
- 프로그램 제목 표시줄과 실행파일 빌드는 Source/app_version.py 값을 사용한다.

======================================================================
V0.1.5
수정일: 2026-09-18
상태: 실시간 자동 판정 및 측정 데이터 재검증 기능 추가, 사용자 검증 대기

주요 변경
- Slanted Edge 실시간 검사에 "전체 ROI PASS 시 자동 결과 표시" 체크박스 추가
- 체크박스 기본값은 OFF이며 OFF 상태에서는 기존 실시간 검사 동작 유지
- 체크 ON 상태에서 활성 ROI 전체가 2회 연속 PASS하면 자동으로 검사 종료
- 자동 확정 시 PASS 판정에 실제 사용된 카메라 프레임을 고정
- 자동 확정된 Slanted Edge 결과표와 MTF 곡선 팝업 표시
- Slanted Edge, RI, Distortion 최종 측정 데이터 자동 저장
- 측정 건마다 날짜·시간·측정 모드·프레임 번호로 구분되는 고유 폴더 생성
- 각 측정 폴더에 original.tiff, result.tiff, measurement.json 저장
- original.tiff는 측정에 실제 사용된 원본 해상도와 uint8/uint16 픽셀 유지
- TIFF 저장 직후 재로딩하여 측정 프레임과 픽셀 완전 일치 검증
- measurement.json에 원본 SHA-256, 측정 설정, ROI, 결과 및 라이브러리 버전 기록
- result.tiff는 원본과 같은 가로·세로 크기로 ROI·Grid·검출점 및 판정 표시
- 파일 메뉴에 "측정 데이터 불러오기" 추가
- 측정 데이터 불러오기 시 TIFF 무결성 확인 후 측정 모드·설정·ROI 복원
- measurement.json이 없는 일반 TIFF/JPEG/PNG는 기존 방식 그대로 사용
- Distortion 분석 불가 시 INVALID 원인과 프레임 번호를 별도 팝업으로 표시
- Distortion 작업 스레드의 예상하지 못한 예외 처리 추가

측정 데이터 저장 구조
- 기본 위치: 프로그램 실행 위치의 measurement_results 폴더
- 날짜별 폴더 아래에 측정별 고유 폴더 생성
- 예: measurement_results/2026-09-18/20260918_153045_327_SlantedEdge_F00001234/
- 카메라 측정은 F######## 프레임 번호를 사용하고 파일 측정은 FILE로 구분
- 같은 측정 ID가 존재하면 _002, _003 순번을 추가하여 덮어쓰기 방지

재검증 조건
- 동일 원본 픽셀, 동일 ROI, 동일 측정 설정, 동일 알고리즘 버전을 기준으로 한다.
- original.tiff가 재측정 입력이며 result.tiff는 결과 확인용으로만 사용한다.
- measurement.json은 선택 파일이며 일반 영상 불러오기에 필수 조건이 아니다.

검증 및 빌드
- 전체 자동 테스트 83개 통과
- SS_PTool_V0.1.5.exe 빌드 및 시작 구동 확인 완료
- .NET 8 SDK가 없고 기존 CameraBridge Release 파일이 있으면 이를 재사용하도록 빌드 개선
- 실제 Camera Link 장비를 이용한 사용자 실시간 검증 후 Git 릴리스 반영 예정

V0.1.4
수정일: 2026-09-10
상태: Camera Link 실시간 검사 기능 추가 버전

주요 변경
- 기존 파일 입력 및 오프라인 검사 기능 유지
- LkProc.Net.dll 기반 Camera Link 전용 .NET 8 브리지 추가
- 메인 프로그램에서 브리지를 자동 실행/종료하는 단일 UI 구성
- 실시간 연결 버튼과 카메라 연결 설정 팝업 추가
- 기본 CAM 파일을 reference_dll의 LK_FLIR 640.cam으로 설정
- CAM 파일 탐색기 선택 기능 추가
- 보드 커넥터 B 기본값 및 A/B 선택·입력 기능 추가
- Mono16 기본값 및 Mono8/Mono16 선택 기능 추가
- 수신 영상 640×512 및 선택 픽셀 형식 검증
- 카메라 30~60 FPS 수신과 화면 갱신 지원
- 실시간 ROI 검사 주기 500ms 기본값 및 1000ms 선택 기능 추가
- 검사 첫 클릭 시 최신 프레임 기반 ROI MTF 수치만 반복 표시
- 검사 두 번째 클릭 시 반복 검사를 종료하고 최종 결과표·그래프·판정 표시
- RI 및 Distortion 검사 시 최신 프레임 화면 고정 후 검사
- 최종검사 및 고정 화면 중에도 백그라운드 카메라 프레임 수신 유지
- 실시간 화면 재개 버튼 추가
- 원본 Mono8/Mono16 프레임을 공유 메모리로 손실 없이 전달

배포 및 실행 조건
- Camera Link 프레임 그래버 드라이버가 설치되어 있어야 한다.
- Microsoft .NET 8 Desktop Runtime이 설치되어 있어야 한다.
- 실행파일 빌드에는 .NET 8 SDK가 필요하다.

V0.0.3
수정일: 2026-09-10
상태: Slanted Edge 계산 방식 선택 기능 추가 버전

주요 변경
- Slanted Edge 모드에 "V0.0.2 LSF 보정 적용" 체크박스 추가
- 체크 ON을 기본값으로 설정하여 V0.0.2 계산 방식 유지
- 체크 ON: ISO 계열 LSF derivative correction 적용 및 100% 초과 MTF 유지
- 체크 OFF: V0.0.1 호환 계산으로 전환
  (LSF derivative correction 미적용, MTF 0~100% clipping 적용)
- 단일 ROI와 전체 ROI 측정에 동일한 계산 방식 선택 적용
- 체크 상태 변경 시 이전 측정 결과를 초기화하여 조건 혼용 방지
- 단일 결과, 전체 결과 및 MTF 곡선 팝업에 적용 계산 방식 표시

측정 결과 영향
- OFF 상태는 V0.0.1 방식의 Slanted Edge MTF 계산 결과와 호환된다.
- ON 상태는 V0.0.2의 고주파 보정 결과를 유지한다.
- 서로 다른 체크 상태의 결과는 계산 조건이 다르므로 혼용하지 않는다.

V0.0.2
수정일: 2026-08-27
상태: Slanted Edge 상용 프로그램 교차검증 개선 버전

주요 변경
- ISO 12233:2014 계열 LSF derivative correction 기본 적용
- np.gradient 중앙차분의 고주파 attenuation 보정
- Slanted Edge MTF 100% 상한 clipping 제거
- MtfCurve에서 sharpening/ringing에 의한 100% 초과값 허용
- MTF 판정 함수에서 100% 초과 측정값 허용
- MTF 그래프 Y축을 실제 최대값에 따라 자동 확장
- Verification linearization 조건을 None, Gamma 1.0으로 명시
- 결과 화면과 Slanted Edge 곡선 팝업에 LSF/Gamma 조건 표시
- Golden PNG 및 상용 프로그램 비교 시 Imatest 설정을
  No linearization 또는 Input Gamma=1로 사용

측정 결과 영향
- V0.0.1보다 MTF50 및 고주파 MTF가 상승할 수 있다.
- Nyquist에 가까울수록 LSF correction 영향이 커진다.
- V0.0.1과 V0.0.2 결과를 동일 알고리즘 결과로 혼용하지 않는다.

V0.0.1
수정일: 2026-08-14
상태: 초기 검증용 개발 버전

주요 내용
- 파일 기반 TIFF, JPEG, PNG 영상 입력
- 8-bit/16-bit 영상 처리
- 마우스 ROI 생성, 선택, 이동, 크기 조절 및 Delete 삭제
- Slanted Edge MTF 측정과 ROI별 전체 MTF 곡선 표시
- Slanted Edge 곡선의 1 lp/mm 간격 보간 표시
- USAF Bar target 기반 CTF 및 환산 MTF 측정
- 평가 주파수 및 목표 MTF 판정
- RI 격자 측정, 최소 RI 판정 및 Contour 팝업
- Checkerboard Distortion 측정
- SMIA TV Distortion 및 Barrel/Pincushion 표시
- Distortion 판정 기준 기본값 2.00%
- 가변 Checkerboard 행/열 추정 및 검출 속도 개선
- Distortion 작업 스레드 적용으로 UI 멈춤 완화
- 광학 설정 JSON 자동 생성, 자동 불러오기 및 자동 저장
- 카메라 입력 해상도와 실제 파일 해상도 역할 분리
- 실시간 카메라 연동은 추후 개발 항목으로 문서화

검증 상태
- UI 및 알고리즘 단위 테스트 수행
- 실제 제품 판정 적용 전 상용 프로그램과 모드별 교차검증 필요
- Distortion Mustache Strong 패턴은 현재 자동 검출 INVALID

빌드 정보
- Python: 3.12 64-bit
- UI: PySide6
- 실행파일 방식: PyInstaller Windows onedir GUI build
- 2026-08-14 실행파일 초기 실행 오류 수정:
  scipy._external.array_api_compat.numpy.fft/linalg 동적 모듈을 빌드에 명시적으로 포함
