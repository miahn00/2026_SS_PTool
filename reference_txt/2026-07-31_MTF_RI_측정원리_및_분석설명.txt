SS Optical Performance Tool
MTF 및 RI 측정 원리와 분석 결과 설명
작성일: 2026-07-31

===============================================================================
1. 문서 목적
===============================================================================

본 문서는 현재 프로그램에 구현된 다음 세 가지 측정 방식의 원리와 결과 해석
방법을 정리한다.

1) Slanted Edge MTF
2) USAF 차트 MTF
3) RI(Relative Illumination, 상대조도)

Slanted Edge와 USAF는 모두 광학 성능을 평가하지만 측정 원리가 다르다.
두 모드의 MTF 값을 완전히 동일한 종류의 값으로 간주하면 안 된다.


===============================================================================
2. 공통 광학 주파수 설정
===============================================================================

2.1 평가 주파수 lp/mm

사용자가 성능을 확인하려는 목표 공간주파수이다.

예:

평가 주파수 = 15 lp/mm

이는 물체면에서 1 mm 안에 15개의 line pair가 존재하는 공간주파수를 의미한다.
한 개의 line pair는 밝은 선 하나와 어두운 선 하나의 조합이다.


2.2 목표 MTF %

측정 결과의 합격 기준이다.

예:

목표 MTF = 30%

유효한 측정 MTF가 30% 이상이면 PASS, 30% 미만이면 FAIL이다.


2.3 Pixel pitch와 렌즈 배율

영상에서 계산한 cycles/pixel을 물체측 lp/mm로 환산할 때 사용한다.

Sensor-side lp/mm =
cycles/pixel × 1000 / PixelPitch(µm)

Object-side lp/mm =
Sensor-side lp/mm × Magnification

Magnification은 렌즈의 실제 광학 배율을 입력한다.

예:
- 0.5X 렌즈: 0.5
- 1X 렌즈: 1.0
- 2X 렌즈: 2.0


===============================================================================
3. Slanted Edge MTF 측정
===============================================================================

3.1 측정 목적

기울어진 하나의 흑백 경계에서 0부터 Sensor Nyquist까지의 연속 MTF 곡선을
계산한다. 사용자가 지정한 평가 주파수의 MTF를 곡선에서 직접 구할 수 있다.


3.2 권장 입력 영상

- 하나의 선명한 흑백 Edge
- ROI 안에는 한 개의 Edge만 포함
- Edge 안에 꼭짓점이나 다른 선이 포함되지 않도록 설정
- Edge는 수평 또는 수직에서 약간 기울어진 상태
- 현재 권장 각도: 1~15°
- 충분한 ROI 크기: 최소 32×32 pixel
- 과도한 노이즈, 포화 및 낮은 대비를 피함


3.3 계산 순서

1) 영상을 Gray 값으로 변환한다.
2) Sobel gradient로 Edge 방향과 위치를 검출한다.
3) 행 또는 열별 Edge 위치를 구한다.
4) 검출 위치에 직선을 피팅한다.
5) 모든 Pixel을 Edge 법선 방향의 거리로 재배치한다.
6) Subpixel oversampling으로 ESF를 생성한다.
7) ESF를 미분하여 LSF를 생성한다.
8) LSF에 Hamming window를 적용한다.
9) FFT로 MTF 곡선을 계산한다.
10) Sensor Nyquist를 초과한 주파수는 제거한다.
11) Pixel pitch와 Magnification으로 object-side lp/mm를 계산한다.
12) 평가 주파수에서 MTF를 보간한다.
13) 목표 MTF와 비교하여 PASS/FAIL을 결정한다.


3.4 ESF, LSF 및 MTF 의미

ESF(Edge Spread Function)
- 흑백 Edge를 통과할 때 밝기가 변하는 형태이다.
- 선명한 광학계는 밝기가 빠르게 변한다.
- 흐린 광학계는 밝기가 완만하게 변한다.

LSF(Line Spread Function)
- ESF를 미분하여 구한다.
- 광학계가 가느다란 선을 얼마나 퍼뜨리는지를 나타낸다.

MTF(Modulation Transfer Function)
- LSF의 주파수 응답이다.
- 공간주파수가 높아질수록 일반적으로 MTF는 낮아진다.


3.5 Slanted Edge 결과 항목

Edge 방향
- VERTICAL: 주로 세로 방향인 Edge
- HORIZONTAL: 주로 가로 방향인 Edge

Edge 각도
- 수평 또는 수직 기준 Edge의 기울기이다.
- 완전히 수평 또는 수직이면 subpixel phase 확보가 어렵다.

R²
- 검출된 Edge 위치가 하나의 직선에 맞는 정도이다.
- 1.0에 가까울수록 직선성이 좋다.
- 현재 품질 기준:
  - 0.980 이상: 양호
  - 0.950 이상 0.980 미만: WARNING 가능
  - 0.950 미만: INVALID

측정 범위(Nyquist)
- MTF를 계산할 수 있는 object-side 주파수 범위이다.
- UI에서는 0(정규화)부터 Nyquist까지 표시한다.

평가/Nyquist %
- 평가 주파수가 Nyquist 상한의 어느 위치인지 나타낸다.

평가/Nyquist % =
평가 주파수 / Nyquist × 100

- 80% 이상이면 고주파 상한에 가까워 결과가 민감하므로 WARNING이다.

ESF 충족/Phase
- Oversampling bin이 실제 Pixel sample로 채워진 비율이다.
- Phase 4/4는 네 개 subpixel phase 구간이 모두 확보됐다는 의미이다.

포화 %
- 영상 Data type의 최솟값 또는 최댓값에 붙은 Pixel 비율이다.
- 포화가 많으면 Edge 응답이 잘려 MTF가 왜곡될 수 있다.

측정 품질
- Edge R², 대비, ESF bin, subpixel phase, 포화, 복수 Edge 및 Nyquist
  여유를 이용하여 GOOD/WARNING/INVALID로 표시한다.
- WARNING은 기본적으로 MTF PASS/FAIL을 바꾸지 않는다.
- INVALID는 신뢰 가능한 MTF 측정이 불가능하다는 의미이다.

MTF @ 평가 주파수
- 연속 MTF 곡선에서 평가 주파수의 MTF를 보간한 값이다.
- Slanted Edge 모드에서는 실제 평가 주파수 위치의 MTF이다.


3.6 Slanted Edge 판정

평가 주파수가 Nyquist 범위 밖:
OUT_OF_RANGE

Edge 또는 Sample 품질이 유효하지 않음:
INVALID

유효한 MTF @ 평가 주파수 >= 목표 MTF:
PASS

유효한 MTF @ 평가 주파수 < 목표 MTF:
FAIL


3.7 해석 예

평가 주파수 = 15 lp/mm
Nyquist = 16.67 lp/mm
MTF @ 15 lp/mm = 42%
목표 MTF = 30%
품질 = WARNING(Nyquist 근접)
상태 = PASS

의미:
- 연속 MTF 곡선에서 15 lp/mm MTF가 42%로 계산되었다.
- 목표 30%를 만족하므로 MTF 판정은 PASS이다.
- 평가 주파수가 Nyquist 상한에 가까우므로 측정 신뢰도에는 주의가 필요하다.


3.8 Slanted Edge 제한사항

- 현재 구현을 ISO 12233 인증 측정으로 표현하지 않는다.
- 실제 카메라 영상으로 상용 기준 프로그램과 교차검증이 필요하다.
- Gamma, Sharpening, Denoise 및 ISP 처리는 MTF 결과에 영향을 준다.
- 평가 주파수가 Nyquist에 가까울수록 Alias와 Sampling 영향이 커진다.


===============================================================================
4. USAF 차트 MTF 측정
===============================================================================

4.1 측정 목적

반복되는 흑백 Bar 패턴의 주파수와 명암 대비를 측정한다.
USAF 모드는 연속 MTF 곡선을 직접 계산하지 않고, 검출된 단일 패턴 주파수에서
CTF를 구한 뒤 MTF로 근사 변환한다.


4.2 입력 조건

- ROI 안에 일정한 간격의 흑백 Bar 패턴을 포함한다.
- 가능하면 하나의 패턴 주파수만 ROI에 포함한다.
- 여러 크기의 Bar 또는 배경이 과도하게 포함되지 않도록 한다.
- 모든 ROI는 공통 평가 주파수, 목표 MTF 및 패턴 허용오차를 사용한다.
- ROI별 별도 주파수 입력은 사용하지 않는다.
- ROI 측정 방향은 Auto로 고정한다.
- 모든 ROI는 활성화 및 전체 판정 포함 상태로 고정한다.


4.3 계산 순서

1) ROI의 수평/수직 평균 profile을 계산한다.
2) 반복 패턴이 강한 방향을 자동 검출한다.
3) FFT peak로 cycles/pixel을 검출한다.
4) Pixel pitch와 Magnification으로 object-side lp/mm를 계산한다.
5) 밝은 Bar와 어두운 Bar level을 측정한다.
6) 검출 주파수에서 CTF를 계산한다.
7) 1차 Coltman 근사로 MTF를 계산한다.
8) 검출 주파수와 평가 주파수의 오차를 계산한다.
9) 주파수 오차가 허용범위 안인지 MATCH/MISMATCH를 결정한다.
10) MATCH이면 MTF @ 검출값과 목표 MTF를 비교한다.
11) MISMATCH이면 OUT_OF_RANGE로 처리한다.


4.4 CTF 계산

CTF =
(Bright - Dark)
/
(Bright + Dark)
× 100

Bright:
- 검출 패턴의 밝은 Bar 평균 level

Dark:
- 검출 패턴의 어두운 Bar 평균 level

CTF가 높을수록 밝은 Bar와 어두운 Bar의 명암 구분이 크다.


4.5 CTF에서 MTF 변환

현재 구현은 1차 Coltman 근사를 사용한다.

MTF @ 검출 주파수 ≈ CTF × π / 4

예:

CTF = 95.55%

MTF ≈ 95.55 × π / 4
    ≈ 75.05%

이는 Slanted Edge에서 직접 계산한 연속 MTF와 동일한 측정 방식이 아니다.


4.6 USAF 결과 항목

평가 주파수 lp/mm
- 사용자가 보려는 목표 주파수이다.
- 모든 ROI에 동일하게 적용한다.

검출 패턴 lp/mm
- ROI 영상에서 실제로 검출된 패턴 주파수이다.

CTF @ 검출 %
- 검출된 패턴의 밝고 어두운 Bar 사이의 명암 대비이다.

MTF @ 검출 %
- 검출된 주파수에서 CTF를 1차 Coltman 근사로 변환한 MTF이다.

패턴 오차 %
- 검출 주파수가 평가 주파수에서 벗어난 비율이다.

패턴 오차 % =
(검출 주파수 - 평가 주파수)
/
평가 주파수
× 100

- 음수: 검출 주파수가 평가 주파수보다 낮음
- 양수: 검출 주파수가 평가 주파수보다 높음

패턴 검증
- 패턴 오차 절댓값이 설정한 허용오차 안인지 나타낸다.
- MATCH: 허용범위 안
- MISMATCH: 허용범위 밖

판정 포함
- 현재 모든 ROI는 Yes로 고정한다.

측정점 상태
- PASS, FAIL, OUT_OF_RANGE, INVALID 중 하나를 표시한다.

사유
- 패턴 주파수 검증 및 목표 MTF 판정 이유를 표시한다.


4.7 USAF 판정

패턴 오차 절댓값 > 패턴 허용오차:
MISMATCH 및 OUT_OF_RANGE

패턴 MATCH
AND
MTF @ 검출 >= 목표 MTF:
PASS

패턴 MATCH
AND
MTF @ 검출 < 목표 MTF:
FAIL

ROI 분석 실패:
INVALID

모든 ROI는 전체 판정에 포함된다.
하나라도 INVALID이면 전체 INVALID,
하나라도 OUT_OF_RANGE이면 전체 OUT_OF_RANGE,
하나라도 FAIL이면 전체 FAIL,
그 외에는 전체 PASS이다.


4.8 USAF 해석 예

평가 주파수 = 15 lp/mm
검출 패턴 = 10.744 lp/mm
패턴 오차 = -28.37%
패턴 허용오차 = 30%
CTF @ 검출 = 95.55%
MTF @ 검출 = 75.05%
목표 MTF = 30%
패턴 검증 = MATCH
상태 = PASS

의미:
- 실제 측정한 패턴 주파수는 10.744 lp/mm이다.
- 평가 주파수 15 lp/mm와의 차이는 -28.37%이다.
- 사용자가 설정한 허용오차 30% 안에 있으므로 MATCH이다.
- 10.744 lp/mm에서의 환산 MTF 75.05%가 목표 30%를 만족하여 PASS이다.

중요:
- 위 결과는 실제 MTF @ 15 lp/mm가 75.05%라는 뜻이 아니다.
- 실제 측정값은 MTF @ 10.744 lp/mm이다.
- 패턴 허용오차에 따라 이 측정값을 판정 대상으로 인정한 것이다.
- USAF 모드에서는 검출 주파수와 평가 주파수가 다를 때 임의 보간이나
  외삽을 수행하지 않는다.


4.9 USAF 제한사항

- 단일 Bar 패턴으로 임의의 다른 주파수 MTF를 계산할 수 없다.
- CTF→MTF 1차 근사는 근삿값이다.
- 실제 USAF 차트 주파수와 검출 lp/mm의 교차검증이 필요하다.
- Gamma, Sharpening, 노이즈 및 포화는 CTF와 MTF 결과에 영향을 준다.

===============================================================================
6. RI(Relative Illumination) 측정
===============================================================================

6.1 측정 목적

영상 중심 밝기를 100%로 정규화하고 주변부 밝기가 중심 대비 얼마나 유지되는지
측정한다. 렌즈와 영상계의 주변광량 저하, Vignetting 및 비대칭을 평가한다.


6.2 권장 입력 영상

- 균일한 광원 또는 균일 방사면
- 균일한 밝기의 평면 Target
- RAW 또는 선형 응답 영상 권장
- Gain, Integration Time 및 조명을 고정
- AGC, Auto Exposure, Gamma, Sharpening 및 Local Tone Mapping OFF 권장
- NUC가 필요한 Camera는 NUC 이후 영상 사용
- 실제 측정에서는 RAW16 사용 권장

JPEG 영상은 UI 및 알고리즘 동작 확인에는 사용할 수 있지만 Gamma, ISP 및
압축 영향 때문에 정량 RI 기준 영상으로 사용하기 어렵다.


6.3 자동 Grid

- 계산 함수 기본 Grid: 5×5
- 현재 RI Contour UI 측정 Grid: 33×25
- 지원 구조: 3 이상의 홀수 행/열
- 예: 3×3, 5×5, 7×5, 9×7
- MTF 수동 ROI와 RI 자동 Grid는 서로 독립적이다.
- 각 Grid cell 전체가 아니라 cell 중앙의 일정 비율을 측정한다.
- 현재 기본 측정 비율은 cell 폭과 높이의 50%이다.
- 즉 cell 각 가장자리에서 약 25%를 제외한다.


6.4 Grid 영역 분류

CENTER
- Grid의 정중앙 cell
- 5×5에서는 row 2, column 2
- 표시 위치는 0부터 시작하는 내부 좌표 기준이다.

CORNER
- 좌상, 우상, 좌하, 우하 네 개 cell

EDGE
- Corner를 제외한 외곽 행 또는 열의 cell

OTHER
- Center와 외곽 사이의 내부 cell


6.5 RI 계산

CenterMean =
중앙 측정 ROI의 평균 Pixel level

Center RI =
100%

각 Grid RI =
GridMean
/
CenterMean
× 100

예:

CenterMean = 1000
CornerMean = 700

Corner RI =
700 / 1000 × 100
= 70%


6.6 RI 출력 항목

Center 평균 밝기
- 중앙 Grid 측정 ROI의 평균 Pixel level이다.

전체 평균 RI
- 모든 Grid RI의 평균이다.

최소 RI
- 전체 Grid 중 가장 낮은 RI이다.

최소 RI 위치
- 최소 RI가 검출된 Grid row와 column이다.

코너 RI
- 좌상, 우상, 좌하, 우하 네 코너의 RI이다.

좌측 평균 RI
- Grid 최좌측 열 RI의 평균이다.

우측 평균 RI
- Grid 최우측 열 RI의 평균이다.

상단 평균 RI
- Grid 최상단 행 RI의 평균이다.

하단 평균 RI
- Grid 최하단 행 RI의 평균이다.

좌우 비대칭
- 좌우 대칭 위치에 있는 Grid RI 차이 중 최댓값이다.

좌우 비대칭 =
max(abs(RI[row,column] - RI[row,last-column]))

상하 비대칭
- 상하 대칭 위치에 있는 Grid RI 차이 중 최댓값이다.

상하 비대칭 =
max(abs(RI[row,column] - RI[last-row,column]))

포화 %
- 입력 영상 Data type의 최솟값 또는 최댓값에 붙은 Pixel 비율이다.

RI Heatmap
- 33×25 실제 Grid 측정값으로 연속 등고선과 Color bar를 표시한다.
- 등고선 화면에는 노이즈 완화를 위한 약한 smoothing을 적용한다.
- smoothing 결과는 표시 전용이며 최소 RI, 코너 RI와 비대칭 통계에는
  사용하지 않는다.


6.7 RI 판정

현재 RI 판정은 사용자가 입력한 최소 RI 판정 기준 하나를 사용한다.
기준값은 optical_settings.json에 자동 저장되고 프로그램 재시작 시 복원된다.
기준 0%는 판정 기준 미설정을 의미한다.

판정식:

최소 RI >= 최소 RI 기준

상태:
- PASS: 측정 최소 RI가 설정 기준 이상
- FAIL: 측정 최소 RI가 설정 기준 미만
- UNSET: 최소 RI 판정 기준이 0%로 미설정
- INVALID: 중앙 평균 0, Grid 생성 실패, 잘못된 영상 또는 분석 불가

코너 RI 및 좌우/상하 비대칭은 측정 결과와 팝업 저장 이미지에 표시하지만
현재 PASS/FAIL 판정 조건에는 사용하지 않는다.

RI 팝업 표시 및 저장 이미지 포함 내용:
- 분석 일시와 원본 파일명
- 판정 방식: 측정 최소 RI >= 설정 기준
- 측정 최소 RI와 위치
- 설정된 최소 RI 기준
- PASS/FAIL/UNSET 결과와 판정 사유
- Center, 평균 RI, 포화, 코너 RI 및 좌우/상하 비대칭


6.8 RI 결과 해석 주의사항

- 주변 RI가 100%를 초과할 수 있으며 계산 오류를 의미하지는 않는다.
- Center가 영상의 최고 밝기라는 가정을 강제하지 않는다.
- 비선형 Gamma 영상에서는 Pixel 값 비율이 실제 광량 비율과 다를 수 있다.
- Color 영상의 Gray 변환값은 채널별 RI 측정과 다르다.
- 제품 검사는 가능하면 선형 RAW 영상에서 수행해야 한다.
- Dark offset이 크면 단순 Mean 비율에 오차가 생길 수 있다.
- 필요하면 추후 Dark Frame을 빼고 RI를 계산한다.


===============================================================================
7. 세 측정 모드의 상태 의미
===============================================================================

PASS
- 유효한 측정 결과가 설정 기준을 만족한다.

FAIL
- 측정은 유효하지만 설정 기준을 만족하지 못한다.

OUT_OF_RANGE
- 요청한 주파수가 계산 범위 밖이거나 USAF 검출 주파수가 허용범위를 벗어난다.
- RI에는 일반적으로 OUT_OF_RANGE보다 INVALID를 사용한다.

INVALID
- ROI, Edge, Grid 또는 영상 품질 문제로 신뢰 가능한 측정값을 만들 수 없다.

WARNING
- 측정값은 계산됐지만 Nyquist 근접, R², 포화 등 주의 조건이 있다.
- 현재 주로 Slanted Edge 품질에 사용한다.


===============================================================================
8. 향후 실제 영상 검증
===============================================================================

- 실제 Camera와 기준 Chart 확보 후 Pixel pitch 및 Magnification 환산 검증
- Slanted Edge 결과를 검증된 기준 프로그램과 비교
- USAF 공칭 주파수와 검출 주파수 비교
- RAW16 균일광 영상으로 RI 검증
- 동일 영상 및 반복 촬영의 평균, 표준편차와 최대 편차 확인
- Gamma, Gain, Exposure, Sharpening 및 NUC 조건 기록
- 검증 완료 후 제품별 PASS/FAIL 기준 확정

Slanted Edge 전체 MTF 곡선 표시 추가
- 전체 ROI 검사 후 ROI 1~4의 object-side MTF 곡선을 한 팝업에 표시한다.
- 원 계산 곡선과 측정 범위 안에서 1 lp/mm 단위로 선형 보간한 점을 함께 표시한다.
- 0 lp/mm는 정규화 기준인 MTF 100%로 표시한다.
- 각 ROI의 Nyquist 주파수 이내 값만 표시하고 범위 밖 외삽은 하지 않는다.
- 평가 주파수는 세로 점선, 목표 MTF는 가로 점선으로 표시한다.
- 팝업에 분석 날짜와 파일명을 표시하며 Matplotlib 도구로 그래프 이미지를 저장할 수 있다.
- 1 lp/mm 값은 별도의 독립 측정값이 아니라 연속 Slanted Edge MTF 곡선의 보간값이다.

Slanted Edge 포화 표시 정책 변경
- 합성 검증 이미지처럼 흑백 영역이 데이터 최소/최대값인 경우에도 "포화 픽셀이 많습니다"를 품질 경고 사유로 표시하지 않는다.
- 포화율 계산값과 결과표의 참고 수치는 유지한다.
- Edge 직선 적합도, 대비, ESF sampling, subpixel phase 및 복수 Edge 검증은 기존대로 유지한다.
