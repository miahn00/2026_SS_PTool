SS Optical Performance Tool
RI(Relative Illumination) 측정 기능 개발 준비
작성일: 2026-07-31

===============================================================================
1. 개발 범위
===============================================================================

- 실제 카메라 연결 전까지 파일로 연 TIFF/JPG 영상을 사용한다.
- MTF용 수동 ROI 최대 4개와 RI 분석 영역은 분리한다.
- RI는 영상 전체에 자동 Grid를 생성해 측정한다.
- 중앙 영역 평균을 100%로 정규화하고 각 Grid의 상대조도를 계산한다.
- 실제 카메라 영상 검증과 다중 프레임 평균은 이후 단계로 미룬다.

===============================================================================
3. 1차 파일 기반 RI 측정 규칙
===============================================================================

3.1 입력 영상
- 원본 정밀도를 유지한 NumPy 영상 사용
- 표시용 8-bit 영상으로 RI를 계산하지 않는다.
- Gray, RGB 영상을 지원한다.
- Alpha 채널 지원 여부는 구현 시 명시한다.

3.2 자동 Grid
- 기본 Grid: 5×5
- 향후 선택 가능 후보: 3×3, 5×5, 7×5, 9×7
- 영상 가장자리의 불완전 영역을 피하도록 유효 분석 영역을 설정한다.
- 각 Grid cell 내부에 일정 여백을 둔 측정 ROI를 사용한다.
- 중앙 cell을 RI 100% 기준으로 사용한다.

3.3 기본 계산

Center RI = 100%

RI(i) =
GridMean(i)
/
CenterMean
× 100

좌우 비대칭 =
대칭되는 좌측/우측 Grid RI 차이의 최댓값

상하 비대칭 =
대칭되는 상단/하단 Grid RI 차이의 최댓값

3.4 출력값
- Center 평균 밝기와 RI 100%
- 전체 Grid 평균 RI
- 최소 RI와 Grid 위치
- 네 코너 RI
- 좌/우 평균 RI
- 상/하 평균 RI
- 좌우 비대칭 %
- 상하 비대칭 %
- RI Heatmap
- 상태와 판정 사유


===============================================================================
4. 현재 RI 판정 기준
===============================================================================

현재 UI 입력:
- 최소 RI 판정 기준 %
- 0은 판정 기준 미설정
- 입력값은 optical_settings.json에 자동 저장하고 재시작 시 복원

판정식:

최소 RI >= 최소 RI 기준

결과 상태:
- PASS: 측정 최소 RI가 설정 기준 이상
- FAIL: 측정 최소 RI가 설정 기준 미만
- UNSET: 기준값이 0으로 설정되어 판정하지 않음
- INVALID: 중앙 평균 0, Grid 생성 실패 또는 영상 형식/데이터가 분석 불가

코너 RI와 좌우/상하 비대칭은 결과 정보로 표시하지만 현재 PASS/FAIL 조건에는
포함하지 않는다. 필요 시 별도의 복합 판정 기준으로 확장한다.

5. UI 구성 계획
===============================================================================

- 측정 모드에 RI 추가
  - Slanted Edge
  - USAF 차트
  - RI

- RI 모드에서는 MTF 평가 주파수, 목표 MTF 및 주파수 허용오차를 숨긴다.
- 영상 위에 자동 Grid 영역을 표시한다.
- 수동 MTF ROI는 RI 계산에 사용하지 않는다.
- 전체 ROI 검사 버튼은 RI 모드에서 전체 RI 측정을 실행한다.

결과표 후보:
- Grid 위치
- 평균 밝기
- RI %
- 영역 분류(Center/Corner/Edge/Other)
- 상태
- 사유

하단 결과:
- 전체 판정
- 최소 RI 및 위치
- 코너 최솟값
- 좌우/상하 비대칭
- RI Heatmap

6. 단계별 구현 순서
===============================================================================

1단계
- 자동 Grid 좌표 생성 함수
- 중앙, 코너, 좌우, 상하 위치 분류
- Grid 좌표 단위 테스트

2단계
- 기존 RI 계산 결과 구조 확장
- 전체 평균, 최소 위치, 코너, 좌우/상하 및 비대칭 계산
- 8/16-bit 합성 균일광 영상 테스트

3단계
- RI 기준 설정과 PASS/FAIL/INVALID 판정 함수
- 포화 및 중앙 기준 유효성 검사

4단계
- 측정 모드에 RI 추가
- 영상 Grid overlay와 결과표 연결
- Heatmap 표시

5단계(실제 카메라 영상 확보 후)
- RAW16 균일광 영상 검증
- NUC, Gain, Integration Time 고정 조건 확인
- Dark Frame 적용 검토
- 다중 프레임 평균과 반복성 검증
