SS Optical Performance Tool - Distortion 측정 원리 및 개발 내용
작성일: 2026-07-31

1. 개발 목표
- 평면의 등간격 흑백 Checkerboard 차트를 이용한다.
- 차트의 행/열 개수와 사각형 크기는 고정하지 않는다.
- 사람이 차트를 놓으면서 생기는 이동, 회전, 확대/축소, 원근 기울기를 자동 보정한다.
- 중앙의 T, 문자, 마커 등으로 일부 교차점이 가려져도 남은 연속 부분 격자로 측정한다.
- 최종 주요 결과는 signed SMIA TV Distortion %와 Barrel/Pincushion 형상이다.

2. 현재 구현된 처리 순서
1) 원본 영상을 grayscale 8-bit 검출 영상으로 정규화한다.
2) 여러 행/열 후보에서 완전하거나 연속된 부분 Checkerboard를 자동 탐색한다.
3) 검출된 교차점 좌표를 sub-pixel 단위로 보정한다.
4) 등간격 정수 격자와 영상 좌표 사이의 평면 homography를 계산한다.
5) homography와 왜곡 중심, 3차/5차 방사 왜곡 계수를 robust loss로 함께 최적화한다.
6) 잔차가 큰 점은 T 문양, 오검출 또는 손상점으로 판단하여 제외한다.
7) 영상 높이 98% 위치에 해당하는 방사 배율 변화로 SMIA-style TV Distortion을 계산한다.
8) 외곽 측정점이 부족하면 외삽하지 않고 INVALID로 처리한다.

3. 출력 의미
- SMIA TV Distortion < 0: Barrel
- SMIA TV Distortion > 0: Pincushion
- 절댓값이 0에 가까움: 왜곡이 작음
- RMS 잔차: 검출점과 최종 모델 좌표 차이의 pixel RMS. 현재 VALID 기준은 1.5 pixel 이하이다.
- 부분 격자: 전체 차트가 아니라 실제 계산에 사용한 연속 교차점의 열×행 수이다.
- 왜곡 중심: 방사 왜곡이 시작되는 중심으로 영상 중심과 다를 수 있다.

4. 사용자 조작
1) 영상 파일을 연다.
2) 측정 모드에서 Distortion을 선택한다.
3) 전체 ROI 검사를 누른다. Distortion 모드는 ROI를 사용하지 않고 전체 영상을 분석한다.
4) 결과 팝업에서 SMIA TV Distortion, 형상, 검출점과 피팅점을 확인한다.
5) 팝업의 Matplotlib 저장 버튼을 사용하면 날짜, 파일명, 결과와 분석 영상을 한 장으로 저장할 수 있다.

5. 유효 조건과 제한
- 차트는 평평하고 사각형 간격이 일정해야 한다.
- 중앙 일부 가림은 허용하지만 영상 외곽의 격자점이 충분히 남아야 한다.
- 반사, 포화, 심한 흐림, 프린트물 자체의 휨은 측정 오차를 만든다.
- 검출점이 중앙에만 있으면 SMIA 경계값을 임의 외삽하지 않고 INVALID로 처리한다.
- 현재 결과는 자체 구현한 SMIA-style 계산이다. Imatest와 소수점 단위의 일치 여부는 동일 원본 이미지 비교 검증 후 확정한다.

6. 현재 샘플 확인
- 파일: 925 3-1 RI (60도 인테그 4500)_02_DIS.jpeg
- 중앙 T 가림을 피한 12×8 부분 격자, 96개 교차점을 검출했다.
- 자세 보정 및 5차 방사 왜곡 모델 피팅이 동작했다.
- 이 수치는 알고리즘 동작 확인값이며 Imatest 교차검증 전에는 제품 판정 기준으로 사용하지 않는다.

7. 다음 검증 항목
- 무왜곡 합성 차트에서 0% 근접 확인
- 알려진 Barrel/Pincushion 왜곡을 주입한 합성 영상에서 부호와 오차 확인
- 회전, 원근, 중앙 가림, 부분 잘림 조건별 반복성 확인
- 같은 원본의 Imatest SMIA TV Distortion 결과와 비교
- 비교 결과에 따라 98% 경계 평가 위치와 SMIA 환산식을 보정

8. Distortion 판정 기준
- UI 명칭: SMIA TV Distortion 판정 기준
- 기본값: 2.00% 이하
- 판정값은 부호를 제외한 절댓값을 사용한다.
- |SMIA TV Distortion| <= 설정 기준: PASS
- |SMIA TV Distortion| > 설정 기준: FAIL
- 측정 결과가 유효하지 않음: INVALID
- 변경값은 optical_settings.json에 자동 저장하고 재시작 시 복원한다.

해상도 적용 원칙
- 파일 분석은 파일에서 읽은 실제 Width/Height를 사용한다.
- 광학 설정의 카메라 입력 해상도와 파일 해상도가 달라도 무시한다.
- 파일을 열 때 카메라 입력 해상도 설정값을 변경하거나 저장하지 않는다.
