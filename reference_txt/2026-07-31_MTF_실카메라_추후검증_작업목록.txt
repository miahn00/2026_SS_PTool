SS Optical Performance Tool
실제 카메라 영상 확보 후 진행할 MTF 검증 작업
작성일: 2026-07-31

===============================================================================
1. 문서 목적
===============================================================================

현재는 파일 기반 개발과 합성 영상 검증까지만 진행한다.
실제 카메라, 렌즈, 기준 차트 및 비교 측정 프로그램이 필요한 작업은
카메라 영상이 준비된 이후에 수행한다.

이 문서의 항목은 검사 결과 저장 기능 개발 전에 반드시 완료해야 하는 작업이
아니며, 실제 측정 환경이 준비된 시점에 다시 검토한다.


===============================================================================
2. 현재 MTF 기능 상태
===============================================================================

[Slanted Edge 모드]
- ROI 최대 4개 측정
- ESF 생성, LSF 계산, FFT를 이용한 연속 MTF 곡선 계산
- Pixel pitch와 렌즈 배율을 적용한 object-side lp/mm 변환
- 평가 주파수에서 MTF 보간
- Nyquist 범위 밖 외삽 금지
- Edge 각도, R², 대비, ESF bin, subpixel phase, 포화 및 복수 Edge 검사
- Gaussian Blur 합성 Edge의 이론 MTF 비교 테스트 완료

[USAF 차트 모드]
- 모든 ROI에 공통 평가 주파수 적용
- ROI 영상에서 실제 바 패턴 주파수 검출
- 검출 패턴의 CTF 계산
- 1차 Coltman 근사로 CTF를 MTF로 변환
- 평가 주파수 대비 검출 주파수 오차 계산
- 설정된 패턴 주파수 허용오차 안에서 MATCH/MISMATCH 판정
- MATCH일 때 MTF @ 검출값과 목표 MTF를 비교해 PASS/FAIL 판정
- MISMATCH일 때 OUT_OF_RANGE 처리


===============================================================================
3. 실제 카메라 영상 확보 후 최우선 검증
===============================================================================

3.1 측정 조건 기록
- 카메라 모델 및 Sensor 정보
- 영상 Width/Height
- Pixel pitch X/Y
- 렌즈 모델과 실제 Magnification
- 차트 종류와 공칭 주파수
- 촬영 거리, 조명, 노출, Gain, Gamma, Sharpening 설정
- 영상이 RAW인지 ISP 처리 영상인지 기록

3.2 lp/mm 환산 검증
- 알려진 공칭 주파수의 USAF 요소를 촬영한다.
- 프로그램의 검출 패턴 lp/mm와 차트 공칭값을 비교한다.
- Pixel pitch와 Magnification 입력값이 실제 광학 구성과 일치하는지 확인한다.
- X/Y 방향에서 환산 결과가 동일한 기준으로 동작하는지 확인한다.
- 오차 원인이 배율, Pixel pitch, ROI 방향 또는 패턴 검출 중 어디인지 구분한다.

3.3 Slanted Edge 기준 측정
- 권장 각도의 단일 Slanted Edge를 촬영한다.
- Edge 안쪽에 모서리나 다른 Edge가 들어가지 않도록 ROI를 설정한다.
- 동일 ROI에서 평가 주파수별 MTF 곡선을 확인한다.
- Nyquist의 80% 이상 주파수 결과는 별도로 기록한다.
- 검증된 상용 프로그램 또는 ISO 12233 대응 프로그램의 결과와 비교한다.

3.4 USAF 차트 기준 측정
- 평가 주파수와 동일하거나 가까운 공칭 USAF 요소를 촬영한다.
- 검출 패턴 lp/mm, CTF 및 환산 MTF 값을 기록한다.
- 패턴 허용오차를 좁은 값부터 단계적으로 변경해 MATCH 경계를 확인한다.
- USAF MTF는 CTF 기반 근사값이며 Slanted Edge 직접 MTF와 동일한 값으로
  간주하지 않는다.


===============================================================================
4. 반복성 및 재현성 검증
===============================================================================

4.1 동일 영상 반복
- 동일한 파일과 동일한 ROI로 최소 5회 측정한다.
- 결과가 매번 동일한지 확인한다.

4.2 ROI 민감도
- ROI 위치를 좌우/상하로 조금씩 이동한다.
- ROI 크기를 단계적으로 변경한다.
- 측정 MTF 평균, 표준편차, 최댓값 및 최솟값을 기록한다.
- 허용할 ROI 위치·크기 변화 기준을 결정한다.

4.3 반복 촬영
- 카메라와 렌즈를 고정한 상태로 최소 5회 다시 촬영한다.
- 노출과 조명을 동일하게 유지한다.
- 촬영 간 MTF 평균, 표준편차 및 최대 편차를 확인한다.

4.4 방향 및 위치별 비교
- 화면 중심과 주변부 ROI를 비교한다.
- 수평 및 수직 방향을 비교한다.
- 필요하면 Tangential/Sagittal 방향 구분을 추후 추가한다.


===============================================================================
5. 영상 품질 조건별 검증
===============================================================================

- 노출 부족 영상
- 과노출 및 포화 영상
- 낮은 대비 영상
- Sensor noise 또는 높은 Gain 영상
- JPEG 압축 영상과 비압축 TIFF 영상
- Gamma, Denoise 및 Sharpening 적용 전후 영상
- Defocus 단계별 영상

각 조건에서 PASS/FAIL뿐 아니라 측정 품질, 오류 사유와 MTF 변화량을 기록한다.


===============================================================================
6. Slanted Edge 알고리즘 추가 검토
===============================================================================

- ISO 12233 수준의 derivative correction 적용 필요성 검토
- Pixel aperture 및 sampling correction 적용 여부 결정
- 비정상적인 MTF 곡선 재상승과 고주파 진동 검출
- Edge 각도 허용 범위 최종 결정
- R², ESF bin, phase, 포화 기준값을 실제 영상 결과로 조정
- 현재 구현을 ISO 인증 측정으로 표현하지 않는다.


===============================================================================
7. USAF 알고리즘 추가 검토
===============================================================================

- 1차 Coltman 근사의 적용 범위와 한계를 실제 영상으로 확인
- 필요하면 고조파 항을 포함한 CTF→MTF 변환 검토
- 패턴 검출 주파수 허용오차의 제품별 기준 결정
- 평가 주파수와 검출 주파수가 다를 때 결과 표기 규칙 재확인
- MTF @ 검출값을 실제 평가 주파수에서 계산한 값으로 표현하지 않는다.


===============================================================================
8. 완료 판정 기준
===============================================================================

- 공칭 차트 주파수와 검출 lp/mm 오차가 정한 기준 안에 들어온다.
- 동일 영상 반복 측정 결과가 동일하다.
- 반복 촬영 결과의 편차가 제품 검사 허용범위 안에 들어온다.
- Slanted Edge 결과가 기준 프로그램과 합의된 오차 안에 들어온다.
- USAF 결과의 CTF 및 MTF 근사값 해석 기준이 확정된다.
- 실제 영상에 맞춘 GOOD/WARNING/INVALID 기준이 확정된다.
- 검증 결과와 사용 조건을 별도 시험성적서 또는 검증 보고서로 남긴다.


===============================================================================
9. 실제 영상 준비 전 진행 가능한 다음 개발
===============================================================================

- 검사 결과 저장 기능은 이미지 저장까지 한 번에 구현한다.
- 동일 검사번호와 동일 저장 폴더를 사용한다.
- 검사 결과 JSON/CSV/Excel 저장
- 원본 영상은 변경하지 않고 별도로 보존
- ROI와 측정값이 표시된 결과 이미지 저장
- 필요한 경우 ROI 확대영상과 분석 그래프 저장
- 저장 폴더 예: Results/YYYY-MM-DD/검사번호/
- 위 결과·이미지 통합 저장 작업은 RI/Distortion 기능 준비 후 진행한다.
- 검사 일시, 제품 정보, 광학 설정 및 판정 사유 기록
- RI(Relative Illumination) 측정 UI와 알고리즘 연결
- Distortion 측정 UI와 알고리즘 연결
- 카메라 DLL 연결부는 인터페이스만 준비하고 실제 연결은 보류
